# D12 运行状态监控（jiankong）

独立的局域网监控与受控运维页面，默认监听 `0.0.0.0:8888`。

## 访问

- 局域网：`http://10.10.10.90:8888`
- 本机：`http://127.0.0.1:8888`

## 页面能力

- 每 5 秒刷新开发端口 `3000`、生产端口 `3001`、Xvfb、VNC `5901`、noVNC `6080`、Chromium/CDP `9222` 与 Multica `19514` 的状态。
- 开发/生产端口可一键直达（生产端口实际监听时才显示）。
- 对已配置的 user service 提供一键启动、一键重启与最近 60 行日志查看。
- Multica 仅提供一键重启和日志。
- 生产服务没有预设启动命令；页面仅监控其端口，避免猜测或变更生产启动方式。

## 控制令牌

因为该页面对局域网开放，所有启动、重启和日志接口均需控制令牌。令牌存放在同目录的 `control-token`（权限 `600`），不会被网页、日志或 API 回显。将令牌填入页面顶部输入框后才可操作。

## 安全边界

程序只操作白名单内的 `systemctl --user` 服务或 `multica daemon restart`，不会接受任意 shell 命令；状态读取不会改动受监控服务。

## 文件

- `server.py`：监控与控制 HTTP 服务
- `jiankong.service`：常驻 user service 定义
- `control-token`：本机控制令牌（勿提交、勿公开）

可选环境变量：`JIANKONG_PORT`（默认 `8888`），`JIANKONG_PRODUCTION_PORT`（默认 `3001`）。
